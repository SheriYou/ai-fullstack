# 转人工坐席分配 — 已确认（PRD §7.4）

**方案**：传 **技能组 ID（groupid）**，已确认。

## 行为

- 传音机器人转人工时传入 Hot70 专属 **技能组 ID**
- **智齿**在技能组内完成具体坐席分配
- 传音侧 **不传 agentid**，不维护坐席池、轮询、在线状态

## M6 测试要点（L1/L3）

| ID | 验证 |
|----|------|
| TC-M6-A01 | 转人工请求含正确 **groupid** |
| TC-M6-A02 | 会话进入 Hot70 技能组；工作台可见 |
| TC-M6-A03 | 技能组内坐席可接单；用户收到人工回复 |

## 不测（本方案范围外）

- 传音侧 A→E 坐席轮询
- 传音维护 agentid / 接待量

## 转人工后机器人状态（Q02 已确认）

- 用户已转人工后 **再发消息 → 机器人不自动回复**
- 会话由 **智齿技能组 / 人工坐席** 承接
- 必测：**TC-M5-010** — 转人工后连发 3 条，均无机器人自动回复
